VESSEL OF ASH — vertical slice
==============================

WINDOWS: run VesselOfAsh.exe (self-contained, no install).
LINUX:   chmod +x vessel_of_ash_linux.x86_64 && ./vessel_of_ash_linux.x86_64
BROWSER: https://xollonox.github.io/vessel-of-ash/

Controls:
  WASD move · mouse look · J/LMB light · K/RMB heavy · L parry
  Space dodge · Q lock-on · E interact · Esc release mouse
  Touch: virtual stick (left) · drag right side to look · on-screen buttons

Sword + blade trail, hair & tinted armour, dungeon props, Kenney CC0 sound
effects, touchscreen support. 23/23 automated gameplay checks green.
All assets CC0 (Quaternius, KayKit, Kenney).
